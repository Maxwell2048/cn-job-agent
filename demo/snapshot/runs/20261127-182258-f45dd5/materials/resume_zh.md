## 项目经历

### 数据分析 Agent：自然语言查询销售数据　独立开发　2026.01 - 2026.04
- **技术架构**：用 LangGraph 搭建数据分析 Agent，模型通过查看表结构、执行只读 SQL 查询、生成图表三个工具，完成自然语言查询销售数据的任务。
- **安全与纠错**：SQL 工具限制为只执行 SELECT 语句并限制返回行数，防止误改数据；查询出错时把错误信息交回模型重写。
- **效果验证**：在 30 个自建业务问题上，Agent 一次给出正确答案的有 24 个，加上一次纠错重试后为 27 个。
- **结果可复现**：回答中说明使用的 SQL 和返回行数，并用 pandas、matplotlib 生成折线图或柱状图，每个回答附带可复现的 SQL 与图表文件，便于非技术人员核对结论。

### 中文新闻文本分类
- **模型对比**：在 10 类中文新闻数据集上比较 TextCNN 与微调 BERT 两种方法，负责数据预处理、训练脚本和评估。
- **实验设计**：用验证集选择学习率和训练轮数，保证两种方法的对比在同一套评估流程下进行。
- **实验结果**：测试集准确率 TextCNN 为 0.86，微调 BERT 为 0.93。

### 智能客服 RAG 问答助手　全栈开发　2025.09 - 2025.12
- **检索与生成**：面向示例电商客服场景搭建 RAG 问答链路：把 320 篇帮助中心文章按标题切分为片段，用开源中文向量模型编码后存入 PostgreSQL 的 pgvector，回答时先检索最相关的 5 个片段再交给大模型生成。
- **引用与评估**：用 LangChain 封装模型调用与检索器，每个回答列出引用文章编号；在自建 60 条测试问题上，检索前 5 名命中正确文章的比例为 52/60。
- **工程实现**：用 FastAPI 编写问答、反馈和文章管理三组接口，React 对话页面支持点赞点踩并写入数据库，系统用 Docker Compose 一键启动，接口有 41 项 pytest 测试。

### 电商销售数据仓库与分析看板
- **数仓建模**：设计星型模型，包括一张订单事实表和商品、客户、日期三张维度表，并用 SQL 编写从原始订单数据到事实表的清洗与装载脚本，处理重复订单和缺失的地区字段。
- **数据规模**：装载约 12 万条示例订单数据，脚本可以重复运行。
- **分析看板**：与组员一起用 Power BI 完成销售分析看板，负责地区销售和复购率两个页面，并编写计算复购率的 DAX 度量。

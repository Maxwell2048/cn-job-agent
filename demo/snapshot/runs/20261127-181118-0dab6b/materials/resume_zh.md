## 项目经历

### 数据分析 Agent：自然语言查询销售数据　独立开发　2026.01 - 2026.04
- **工具设计**：用 LangGraph 搭建数据分析 Agent，模型通过查看表结构、执行只读 SQL 查询、生成图表三个工具完成任务。
- **安全与纠错**：SQL 工具限制为仅执行 SELECT 语句并限制返回行数，避免误改数据；查询出错时把错误信息交回模型重写。
- **效果验证**：在 30 个自建业务问题上，Agent 一次给出正确答案的有 24 个，加入一次纠错重试后为 27 个。
- **结果核查**：回答中说明所用的 SQL 和查询行数，用 pandas 和 matplotlib 生成折线图或柱状图，每个回答附带可复现的 SQL 与图表文件。

### 智能客服 RAG 问答助手　全栈开发　2025.09 - 2025.12
- **检索增强**：搭建客服 RAG 问答链路：320 篇帮助中心文章按标题切分，用开源中文向量模型编码后存入 pgvector，检索最相关的 5 个片段交给大模型生成带引用的回答。
- **链路封装**：用 LangChain 封装模型调用和检索器，并要求每个回答列出引用的文章编号，方便核对结论来源。
- **检索评测**：在自建的 60 条测试问题上，检索前 5 名命中正确文章的比例为 52/60。
- **工程实现**：用 FastAPI 实现问答、反馈和文章管理三组接口，React 对话页面支持点赞点踩并写入数据库；Docker Compose 一键启动，接口有 41 项 pytest 测试。

### 中文新闻文本分类
- **模型对比**：在 10 类中文新闻数据集上比较 TextCNN 和微调 BERT 两种方法，负责数据预处理、训练脚本和评估。
- **训练调参**：用验证集选择学习率和训练轮数，保证两种方法的对比条件一致。
- **评估结果**：测试集准确率 TextCNN 为 0.86，微调 BERT 为 0.93。

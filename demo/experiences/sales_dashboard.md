# 电商销售数据仓库与分析看板

## 基本信息
- 项目类型：研究生课程项目，3 人小组（虚构演示数据）。
- 时间：2025-03 至 2025-06。
- 技术栈：SQL、PostgreSQL、Python、pandas、Power BI。

## 我的工作 数据仓库建模
我负责设计星型模型：一张订单事实表和商品、客户、日期三张维度表，并用 SQL 写了从原始订单数据到事实表的清洗和装载脚本，处理了重复订单和缺失的地区字段。
结果：装载约 12 万条示例订单数据，脚本可以重复运行。
相关能力：data warehouse, star schema, SQL, ETL, data cleaning, PostgreSQL.

## 我的工作 分析看板
我和组员一起用 Power BI 做了销售分析看板，我负责其中的地区销售和复购率两个页面，并写了计算复购率的 DAX 度量。
结果：小组作业获得 A 等级（虚构）。
相关能力：Power BI, DAX, data analysis, teamwork.
